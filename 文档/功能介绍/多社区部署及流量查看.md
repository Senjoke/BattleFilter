# 多社区部署及流量查看指南

本文档旨在说明如何使用一套后端服务来支持多个社区的独立部署（多租户架构），以及如何通过 API 接口获取当前社区的流量与访问指标。

## 一、 多社区独立部署说明

系统通过 `tenantId`（租户ID）来实现多社区的数据与状态隔离。在部署新社区时，您只需要分别配置前端的 `VITE_TENANT_ID` 和后端的 `ADMIN_PASSWORDS`，无需部署多套后端代码。

### 1. 前端配置（区分社区标识）
在每个社区对应的前端项目根目录下，修改 `.env` 文件，配置该社区专属的租户 ID。

例如，对于 `ameili` 社区，修改 `frontend/.env`：
```env
VITE_API_BASE_URL=https://ow.senjoke.top/api
VITE_TENANT_ID=ameili
```

对于 `ameili1` 社区，修改其对应的 `frontend/.env`：
```env
VITE_API_BASE_URL=https://ow.senjoke.top/api
VITE_TENANT_ID=ameili1
```
**注意**：修改 `.env` 后需要重新执行 `npm run build` 打包前端，并将生成的 `dist` 目录部署到对应社区的服务器或静态托管平台上。

### 2. 后端配置（配置独立密码）
后端通过解析 JSON 格式的环境变量来为不同社区分配独立的管理员密码。

在后端的 `backend/.env` 文件中，找到或添加 `ADMIN_PASSWORDS` 字段，填入合法的 JSON 字符串：
```env
# 所有的密码都集中在这里配置，"default" 作为回退选项
ADMIN_PASSWORDS={"default":"BattleFilter_Admin_2026!", "ameili":"admin123", "ameili1":"456789"}
```
**注意**：
- 必须使用双引号 `"` 包裹键和值，否则会引发 JSON 解析错误，导致无法登录。
- 每次修改后端的 `.env` 文件后，必须重启后端服务（如 `pm2 restart all`）使配置生效。

## 二、 流量指标查看 (`/api/admin/metrics`)

系统提供了一个用于查看全局及当前社区流量指标的接口。由于该接口属于管理端 API，必须携带有效的鉴权 Token 才能访问。

### 1. 获取鉴权 Token (Login)
在调用指标接口前，您需要先通过登录接口获取管理员 Token。

- **接口地址**：`POST /api/admin/login`
- **请求头 (Headers)**：
  - `X-Tenant-Id`: 当前请求的社区 ID（如 `ameili`）
- **请求体 (Body - JSON)**：
  ```json
  {
    "username": "admin",
    "password": "当前社区在后端 .env 中配置的专属密码"
  }
  ```
- **响应示例**：
  ```json
  {
    "success": true,
    "code": 200,
    "message": "登录成功",
    "data": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    }
  }
  ```

### 2. 调用流量指标接口
获取到 Token 后，即可请求流量指标接口。

- **接口地址**：`GET /api/admin/metrics`
- **请求头 (Headers)**：
  - `Authorization`: `Bearer <您刚刚获取到的 token>`
  - `X-Tenant-Id`: 当前请求的社区 ID（如 `ameili`）
- **响应示例**：
  ```json
  {
    "success": true,
    "code": 200,
    "message": "获取系统指标成功",
    "data": {
      "globalVisits": 1500,    // 系统总访问量（所有社区汇总）
      "tenantVisits": 350,     // 当前社区的总访问量
      "globalDau": 120,        // 系统今日全局日活（估算）
      "tenantDau": 45          // 当前社区今日日活（估算）
    }
  }
  ```

### 3. 常见报错排查
- **401 Unauthorized ("用户未授权" / "令牌无效或已过期")**：
  检查请求头中是否正确携带了 `Authorization: Bearer <token>`，以及 Token 是否已经过期（默认有效期 24 小时）。
- **403 Forbidden ("无权访问该社区的管理后台")**：
  您当前使用的 Token 属于另一个社区。Token 在生成时绑定了 `tenantId`，跨社区不可通用。请重新调用登录接口获取目标社区的专属 Token。
- **500 Internal Server Error ("管理员密码配置格式错误")**：
  请检查后端 `.env` 中的 `ADMIN_PASSWORDS` JSON 格式是否正确，尤其是引号的使用。
