# BattleFilter 守望先锋赛事系统 - 宝塔面板部署指南

对于习惯使用可视化服务器管理工具的开发者，**宝塔面板（BT Panel）** 提供了非常友好的部署体验。本文档将详细指导您如何使用宝塔面板一步步部署本项目的数据库、后端和前端。

---

## 🛠️ 1. 宝塔面板环境准备

登录您的宝塔面板，在左侧菜单栏点击 **软件商店**，搜索并安装以下必备软件：
1. **Nginx**: 推荐安装 `1.22` 或更高版本（用于部署前端及反向代理）。
2. **PostgreSQL**: 推荐安装 `14.x` 或 `15.x` 版本（用于存储赛事数据）。
3. **PM2 管理器 / Node.js 版本管理器**: 在软件商店搜索“PM2”，安装并打开。在它的设置中安装 Node.js `v18.x` 或以上版本。

---

## 🗄️ 2. 部署数据库 (PostgreSQL)

1. 点击左侧菜单栏的 **数据库**，在顶部选择 **PgSQL** 选项卡。
2. 如果提示需要设置 PostgreSQL 的 `postgres` 密码，请先设置并牢记。
3. 点击 **添加数据库** 按钮：
   - **数据库名**: `battlefilter`
   - **用户名**: `admin`（或您自定义的名字）
   - **密码**: 设置一个强密码，例如 `Your_Strong_Password_123`
4. 提交后，数据库就准备就绪了。记住这里的 **数据库名**、**用户名** 和 **密码**，后端马上要用到。

---

## ⚙️ 3. 部署后端服务 (Node.js/Express)

### 3.1 上传代码
1. 在您本地电脑上，将 `backend` 文件夹打包压缩为 `backend.zip`（注意：**不要**包含 `node_modules` 和 `dist` 文件夹）。
2. 在宝塔面板左侧点击 **文件**，进入 `/www/wwwroot/` 目录。
3. 新建一个文件夹，命名为 `battlefilter-backend`，进入该文件夹。
4. 点击 **上传**，将刚才的 `backend.zip` 上传并解压到此目录。

### 3.2 配置环境变量
1. 在解压后的 `/www/wwwroot/battlefilter-backend/` 目录下，找到或新建 `.env` 文件。
2. 双击编辑该文件，填入刚才在宝塔创建的数据库信息：
   ```env
   PORT=3000

   # 数据库连接配置 (根据宝塔实际创建的填写)
   DB_HOST=127.0.0.1
   DB_PORT=5432
   DB_USER=admin
   DB_PASSWORD=Your_Strong_Password_123
   DB_NAME=battlefilter

   # JWT 密钥
   JWT_SECRET=YOUR_SUPER_SECRET_KEY_HERE
   ```

### 3.3 安装依赖与编译启动
1. 在当前 `/www/wwwroot/battlefilter-backend/` 目录下，点击宝塔文件管理器顶部的 **终端** 按钮。
2. 在弹出的终端窗口中依次执行以下命令：
   ```bash
   # 安装依赖
   npm install

   # 编译 TypeScript
   npm run build
   ```
3. 编译完成后，关闭终端。点击宝塔左侧的 **软件商店**，打开刚才安装的 **PM2 管理器**。
4. 点击 **添加项目**：
   - **启动文件**: 点击文件夹图标，选择 `/www/wwwroot/battlefilter-backend/dist/index.js`。
   - **运行目录**: 自动生成。
   - **项目名称**: `battlefilter-api`
5. 点击提交，此时后端 API 服务就已经在 `3000` 端口成功运行了！

---

## 🌐 4. 部署前端静态网站 (Vue 3)

### 4.1 本地打包前端代码
1. 在您的本地电脑上，进入 `frontend` 文件夹。
2. 找到 `.env` 文件，确保 API 路径配置为（如果同服务器部署，填 `/api` 即可）：
   ```env
   VITE_API_BASE_URL=/api
   ```
3. 在本地终端执行打包命令：
   ```bash
   npm install
   npm run build
   ```
4. 打包完成后，`frontend` 目录下会生成一个 `dist` 文件夹。将 `dist` 文件夹内部的所有文件全选，打包成 `dist.zip`。

### 4.2 宝塔创建站点并上传
1. 点击宝塔左侧的 **网站**，点击 **添加站点**。
   - **域名**: 填入您的服务器 IP 或绑定的域名。
   - **根目录**: 默认为 `/www/wwwroot/您的域名或IP`。
   - **数据库**: 选择 `不创建`（数据库刚才已经单独建好了）。
   - **PHP版本**: 选择 `纯静态`。
2. 提交后，点击该网站右侧的 **根目录** 链接，进入站点文件夹。
3. 清空里面默认生成的 `index.html` 和 `404.html`。
4. 点击 **上传**，将刚才本地的 `dist.zip` 上传并解压，确保站点的根目录下直接就是 `index.html`、`assets` 等文件。

### 4.3 配置 Nginx (解决404与跨域)
这是最关键的一步，由于前端是单页应用（SPA），且我们需要解决请求后端的跨域问题。

1. 在宝塔的 **网站** 列表中，点击刚才创建的站点右侧的 **设置**。
2. 点击左侧的 **配置文件** 选项卡。
3. 在配置文件代码中找到 `location ~ .*\.(gif|jpg|jpeg|png...` 这一段，在**它上方**插入以下两段配置：

   ```nginx
   # 1. 解决 Vue Router 刷新报 404 的问题
   location / {
       try_files $uri $uri/ /index.html;
   }

   # 2. 反向代理，将 /api 请求转发给后端的 3000 端口
   location ^~ /api/ {
       proxy_pass http://127.0.0.1:3000/api/;
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header REMOTE-HOST $remote_addr;
   }
   ```
4. 点击 **保存**。

---

## 🛡️ 5. 安全与防火墙放行设置

1. 点击宝塔左侧的 **安全** 菜单。
2. 确保放行了网站需要的端口：
   - **80** 端口 (HTTP 默认)
   - **443** 端口 (如果配置了 HTTPS)
3. **注意**：由于我们在 Nginx 里配置了反向代理（`/api/` 转发给本地 `3000`），因此您 **不需要** 在防火墙里对外开放 `3000` 端口，这样可以更好地保护后端 API 的安全。
4. **云服务器控制台配置**：如果您使用的是阿里云、腾讯云等，切记也要去云服务商的控制台 -> **安全组** 中，放行 `80` 和 `443` 端口。

---
🎉 **部署完成！**
现在您可以在浏览器中直接输入您的域名或服务器 IP 访问赛事系统了！
如果后端接口有修改，只需重新上传修改的文件，执行 `npm run build` 后，在 PM2 管理器中点击重启 `battlefilter-api` 即可。
