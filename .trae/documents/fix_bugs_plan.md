# 修复报名特殊字符与 Nginx 404 问题计划

## 1. 现状分析

1. **战网昵称校验过严**：目前前端 `RegistrationView.vue` 和后端 `registration.ts` 中的正则表达式限制了只能使用中文或英文字母（且有限制组合）。对于如“铁䨻拳䨻大䨻人”这种包含生僻汉字（如“䨻”）或日韩语字符的合法战网 ID，会被系统错误拦截，导致报名失败。
2. **SPA 路由刷新 404**：前端使用 Vue Router 的 History 模式。由于前端代码打包后部署在宝塔面板的纯静态站点中，如果用户直接访问或刷新非根路径（如 `/board`），Nginx 会尝试在服务器物理路径中寻找 `board/index.html` 文件，找不到则返回 404 错误。

## 2. 改造方案 (Proposed Changes)

### 2.1 修复报名特殊字符问题（代码修改）

暴雪战网昵称规则允许包含多国语言字母和数字（之前的规则不变）。我们将使用支持 Unicode 的正则来完美兼容。

**文件 1：`frontend/src/views/RegistrationView.vue`**

* **修改内容**：将 `validateNickname` 函数中的正则表达式替换为支持所有语言文字和生僻字的 Unicode 正则。

* **具体实现**：
  将正则改为 `/^[\p{L}\p{M}][\p{L}\p{M}\p{N}]{1,11}#[0-9]{4,6}$/u`。

**文件 2：`backend/src/routes/registration.ts`**

* **修改内容**：同步更新后端的战网昵称校验逻辑。

* **具体实现**：
  将 `nicknameRegex` 改为 `/^[\p{L}\p{M}][\p{L}\p{M}\p{N}]{1,11}$/u`。
  修改对应的返回 400 错误信息文本，使其与前端提示保持一致。

### 2.2 修复部分页面刷新或跳转 404 问题（运维配置配置）

此问题无需修改项目源代码，而是需要在宝塔面板的网站设置中添加 Nginx 伪静态（URL Rewrite）配置。本项目在 `文档/系统说明文档/宝塔面板部署文档.md` 中其实已有说明。

**解决步骤（供用户参考，无须代码修改）**：

1. 登录宝塔面板，进入 **网站** 列表，找到部署前端静态页面的站点，点击右侧的 **设置**。
2. 点击左侧的 **伪静态**（或 **配置文件**）选项卡。
3. 添加以下 Nginx 配置，将所有找不到的请求重定向到 `index.html`：

   ```nginx
   location / {
       try_files $uri $uri/ /index.html;
   }
   ```
4. 保存配置，刷新页面即可解决 404 问题。

## 3. 假设与决策 (Assumptions & Decisions)

* 决策：采用 Unicode 属性类 `\p{L}` (字母)、`\p{M}` (附加符号) 和 `\p{N}` (数字) 来校验战网昵称。这是一种非常稳妥的做法，既放开了日文、韩文、生僻汉字的限制，又保证了不会混入非法标点符号（如 `!@#$`）。

## 4. 验证步骤 (Verification steps)

1. 运行本地开发环境，测试报名输入 `铁䨻拳䨻大䨻人#5166`，验证是否能成功通过前端验证并成功写入数据库。
2. 测试输入 `さくら#1234` 或 `송하나#5678` 验证多语言字符是否正常。
3. 测试以数字开头如 `123test#1234`，验证是否能正确被拦截。
4. 提示用户按照文档在宝塔中修改配置，验证路由刷新 404 问题是否解决。
